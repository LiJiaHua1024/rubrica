Scope: implement the complete feature gap review accepted on 2026-09-23. Preserve native DirectWrite/Direct2D rendering, whole-paragraph line breaking, OpenType MATH layout, and the completed bidirectional text support.

## Acceptance checklist

- [x] Typography profiles: editable Latin, Chinese, Japanese, Korean, emphasis, code and math fonts; font size, leading, tracking, paragraph spacing and indentation; named saved profiles and a book preset; settings UI and persistence.
- [x] East Asian typography: punctuation compression and hanging policies, narrow-column ragged fallback, language-aware Japanese and Korean font selection and Korean keep-all breaking.
- [x] Export: whole-document PNG with width/scale controls and native selectable-text PDF; pagination with heading/paragraph protection, repeated table headers and continued footnotes; reading typography and colours retained.
- [x] Multiple documents: tabs with preview/pinned behavior, a visible tab strip, resizable docked workspace tree, recent documents, per-document positions and restored session.
- [x] Source reading: syntax-coloured source view preserving the original text, position-preserving reload and mode switching; configurable external editor command. (The editor executable and `{file}`/`{line}`/`{column}` argument template are configurable.)
- [x] Plain text: literal TXT parsing, automatic/manual encoding selection, paragraph rules, chapter outline, chapter-window layout for large files, background chapter prefetch, previous/next document navigation and TXT typography binding. (UTF-8 and explicit legacy code-page books are indexed and read by chapter.)
- [x] Wide content: overflow indication and horizontal formula panning/full preview, wide tables extending into available margins, and full-size image viewing; the table margin-borrow control is available in the text menu.
- [x] Markdown single-newline policy: global preference and per-document override, preserved across reload.
- [x] Cross-document heading links: retain and decode the fragment, open/reuse the document and jump to the heading.
- [x] Formula copying: copy selected inline/display math with delimiters, including inside paragraphs and table cells.
- [x] Mermaid diagrams (Telari gap review G1): ` ```mermaid ` fences draw flowcharts (node shapes, arrow variants, edge labels both ways, subgraphs, self-loops), sequence, state (including `[*]` and `: transition labels`), class, ER, pie, mindmap and tree view (`treeView`/`treeView-beta`) diagrams through a new dependency-free `rubrica-mermaid` crate (parse to layout to scene); lines and words follow the light/dark palettes; diagram words are shaped through the same DirectWrite pipeline and appear as real selectable text (`ActualText`) in exported PDFs; unreadable or oversized fences degrade to the code block with a one-line reason above it and never panic; `--report` / `--report --shapes` count elements, links, shapes and labels per diagram and check every piece stays inside its scene; `fixtures/mermaid-*.md` and 53 pure-function parser/layout tests cover it -- including corpus-wide layout invariants: every edge label (backdrop included) stays clear of every other, and every subgraph panel holds its members while overlapping no box or label that is not one of them -- with before/after `--report` numbers recorded in `TELARI-GAP-STATUS.md`.
- [x] Raw HTML semantics (Telari gap review G2): inline HTML is read for what it means rather than printed -- `<b>`/`<strong>`/`<i>`/`<em>`/`<code>`/`<del>` dress their words through the existing span styles; `<sub>`/`<sup>` are real lowered/raised runs at the footnote-citation scale (one 0.7 em mark, raised 0.62 em or sunk 0.2 em of the block); `<br>` keeps its line break and the separator tags (`<td>`/`<th>`/`<tr>`) part fields without gluing words or inserting a space between two CJK sides; `<span>`, `<a>` and tags with no typographic answer keep their words and lose their markup; a raw block holding a whole `<table>` or `<details>` is shown as the source it was written as (a highlighted, copyable `lang=html` code block) while a bare wrapper is dropped; `<img>` draws (alt carried, relative/percent-escaped paths through the existing image store, Typora's `style="zoom:87%"` applied to the natural size before the column fit); **Show HTML image tags** (default on, persisted as `HKCU\Software\Rubrica\HtmlImages`, 11-language menu label, `--no-html-images` for headless runs) reads an `<img>` as its alt words instead; fenced/inline code keeps HTML verbatim and `Document::source` is untouched. `fixtures/html.md` (+ two small PNGs) covers the behaviors; `--report` gained an `images` line printing each figure's placed size (and its footnote census now requires a citation action, so a formula's `mc<sup>2</sup>` is not miscounted as a citation).
- [x] Pandoc scripts (Telari gap review G3): `H~2~O` and `x^2^` are read as real lowered/raised runs in prose and table cells, with the scale and the two shifts learned once from the `MATH` table of the formula face (`ScriptPercentScaleDown`, `SuperscriptShiftUp`, `SubscriptShiftDown` -- clamped, the design's 0.7/0.62/0.2 standing in when no face answers), so an author's `^`/`~`, a `<sup>`/`<sub>` and a citation's `¹` are set with one pair of numbers. A run of exactly one unescaped mark pairs with the next one whose content holds no unescaped whitespace (`\ ` is allowed and prints as a non-breaking space), no object, no unescaped mark run of two or more, and no mark another pair already spent. A single `~` at a word boundary is taken back from pulldown's strikethrough, while `~~deletion~~` keeps its meaning; unpaired marks, escaped marks and runs of two or more print as written, and inline/fenced code is immune. `--report` gains a `scripts` line (raised/lowered counts, the three numbers and the face they came from) that prints only on a page that used the syntax, and `fixtures/subsuper.md` covers every accepted and refused shape.
- [x] Highlighted text (Telari gap review G4): `==text==` is read as a fluorescent band behind its words -- in prose, table cells and definitions alike. A pair is a run of exactly two unescaped signs, opened where a real character follows and closed at the next run whose content is non-empty and does not end in whitespace; escaped signs, unpaired signs and runs of three or more print as written (the last is a documented leave: Pandoc cuts a pair out of one), and inline/fenced code is immune. A mark wraps emphasis, strong, deletion, a link, a formula and a script without disturbing any of them, reaches across a soft break, and `Block.highlights` counts the pairs per block for the report's `highlight` line. The band is painted in its own pass under the runs (so the words sit on top of it) from `Palette.highlight` in both the light and dark themes, its contrast and the display list's reading order held by app tests. **Show `==text==` as a highlight** (default on, `HKCU\Software\Rubrica\Highlights`, 11-language label, `--no-highlights` for headless runs) reads the same page with every mark as written. `fixtures/highlight.md` covers the shapes.
- [x] Colour themes (Telari gap review G5): user TOML themes under `%APPDATA%\Rubrica\themes` are read by a self-contained parser (a small TOML subset of `[meta]`/`[colors]`/`[chrome]`, quoted strings and `#` comments -- no new dependency), resolved as layers: fourteen `[colors]` keys and nine `[chrome]` keys, keys left out inherited down a `based_on` chain (max 8 themes, ring-checked, appearance-matched) that ends at the built-in pair, the six furniture colours (sidebar, sidebar text, tab label, active tab, label on it, dividers) settled from the page's own colours unless the file says otherwise. Six built-ins ship with the binary: the `Default` pair (byte-identical rendering to `Palette::of`), the `Mono` pair (no hue) and the `Solarized` pair (published hues, quiet inks deepened to the reader's 4.5:1 bar, deviation noted in the README). Body-of-file mistakes -- a key that is not a colour -- cost only that key and are named in the listing; a file with no `name`, no valid `appearance`, bad UTF-8, over 64 KiB, a duplicate or built-in name, or an unresolvable chain is set aside whole with its reason. Light and dark slots live in `HKCU\Software\Rubrica` (`ThemeLight`/`ThemeDark`; empty string = the default), a stale or cross-appearance name falls back to the default and the menu row says why (11 languages). The **Colour theme** submenu holds the two slot submenus (current theme ticked), **Copy as My Theme…** (writes the resolved 23 colours to the folder as a new name, never stacking ` Copy` suffixes) and **Open Themes Folder**; the folder is stamped and compared on the document timer, so a saved file changes the menu and the page within the second. Headless: `--theme <name|path>` (case-insensitive name; strict in `--report`/exports -- a name nothing answers to, or a light theme with `--dark`, refuses -- while the window reports it on the console and draws the default), `--list-themes` listing built-ins, files read, files not read with reasons and both slots, and a `theme` line in `--report` only when a theme was asked for, so a page nobody themed reports byte-identically to earlier builds.
- [x] Table lines and inline code capsules (Telari gap review G6): two drawing switches, both changing only ink and never a coordinate. A table is drawn either as the full grid or as the printed table's three rules (`TableLines::Grid`/`Booktabs` on `Theme`, default grid): booktabs lays a heavier rule above the table, the header rule under the header, and a heavier rule at the foot where the grid's last row line stands, dropping every row line and every vertical -- the same lines the layout already placed, so no cell, row, column or reading position moves. An inline code span is drawn either as the monospaced face and its own ink or on a capsule of its own (`Theme::code_capsule`, default off; `ResolvedStyle.capsule` = the switch and `InlineStyle::CODE`, so a fence's text never qualifies): the capsule is one drawn `Op::Rect` per style **span** per line (keyed by span, not style, so `` `a` and `b` `` is two boxes, never one across the word between), a 0.15 em horizontal pad over the span's advance at the highlighter band's own height (`BAND_TOP`/`BAND_H`) in `ColorRole::Surface` (`code_bg`), painted before the runs and never measured. `TableSpan` carries the table's `left`/`right` and the closing rule (`cut`: thickness + colour) of its style, and `write_pdf` fills that rule at a cut segment's lower edge, so every page segment of a table printed across pages carries a complete frame. Switches live in the menu's **Table lines** and **Inline code** submenus (11 languages), in `HKCU\Software\Rubrica` (`TableLines`/`CodeCapsule`, both defaulting to the design every page was drawn with), and headlessly in `--tables grid|booktabs` / `--inline-code plain|capsule` (a word this build does not know is refused, exit 1); `--report` prints a `tables` or `inline code` line only when the non-default design was asked for, so a page nobody switched reports byte-identically. `fixtures/tables.md` covers prose, cells, a heading, a definition, a wrapped span and a 26-row table `--pdf-height` cuts.
