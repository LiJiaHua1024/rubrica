# 化学方程式

- **与卤素及硫**：钠在氯气中剧烈燃烧，生成大量白烟（$2Na + Cl_2 \xrightarrow{点燃} 2NaCl$）；而当钠与硫粉混合研磨时，机械能跨越了活化能壁垒，瞬间发生爆炸性的电子转移（$2Na + S = Na_2S$）。

## 常规 LaTeX

燃烧：$2Na + O_2 \xrightarrow{\Delta} Na_2O_2$。

电解：$2NaCl(熔融) \xrightarrow{通电} 2Na + Cl_2\uparrow$。

可逆反应：$N_2 + 3H_2 \rightleftharpoons 2NH_3$。

上下条件：$N_2 + 3H_2 \xrightleftharpoons[高温、高压]{\text{催化剂}} 2NH_3$。

沉淀与电荷：$Ag^+ + Cl^- \rightarrow AgCl\downarrow$；$\mathrm{SO_4^{2-}}$。

各类箭头：$A \xleftarrow{条件} B$；$A \xleftrightarrow{条件} B$；$A \xRightarrow{条件} B$；$A \xLeftrightarrow{条件} B$；$A \xleftrightharpoons{条件} B$。

## 常用 mhchem 写法

燃烧：$\ce{2Na + Cl2 ->[点燃] 2NaCl}$。

可逆反应：$\ce{N2 + 3H2 <=>[催化剂][高温、高压] 2NH3}$。

离子：$\ce{2NH4+ + SO4^2- -> (NH4)2SO4(aq)}$。

气体：$\ce{Zn + 2H+ -> Zn^2+ + H2 ^}$。

沉淀：$\ce{Ag+ + Cl- -> AgCl v}$。

结晶水：$\ce{CuSO4 * 5H2O ->[\Delta] CuSO4 + 5H2O}$。

化学键：$\ce{H-Cl}$；$\ce{O=O}$；$\ce{N#N}$。

同位素：$\ce{^{14}_{6}C}$。
